# 모던문고 (1895—1936) · UI/UX 기준

이 서재의 정체성(종이 바탕, 세리프 제목, 그려서 만든 표지, 작가마다 다른 괘선)은 그대로 두고,
국내외 전자책·서재 서비스가 오래 다듬어 온 사용 관례만 가져온다. 새 화면이나 고침은 아래 기준을 통과해야 한다.

## 참고한 서비스와 가져온 것

## 기준

### 1. 책이 먼저 보인다
- 데스크톱(1280×800 안팎) 첫 화면에 서가 첫 줄 표지 윗부분이 보여야 한다. 제목부(masthead)가 화면의 절반을 넘지 않는다.
- 휴대폰 첫 화면은 제목부를 머리글 크기로 줄인다(이미 적용).
- '읽는 중'이 있으면 서가보다 위, 첫 화면 안에 있다.

### 2. 정보 위계
- 표지 아래 라벨 순서: **제목 → 갈래·저자 → 분량·시간 → 동작(열기 영문/한글/대역)**.
  읽는 정보가 먼저, 누르는 것은 마지막.
- 강조색(accent)은 '진행·선택·한국어판'에만 쓴다. 장식에 쓰지 않는다.

### 3. 글자
- 한글 UI 글자는 **12px 이상**. 숫자 배지·키 표시(kbd)만 예외로 10px까지.
- 표지 안 글자는 '그림'이므로 예외(cqw로 표지 크기를 따라감).
- 본문(한국어)은 `word-break: keep-all` + **왼쪽 정렬이 기본**, 양쪽 정렬은 설정에서 고른다.
  리디·교보 앱은 양쪽 정렬이 기본이지만 그건 글자 사이까지 벌리는 자체 조판기 덕이다.
  브라우저(Chrome)는 `text-justify: inter-character`를 지원하지 않아 낱말 사이만 벌어지고,
  휴대폰 폭에서는 한 줄에 큰 구멍이 생긴다(2026-10 확인). 지원되면 다시 검토한다.
- 대비: 본문·라벨 4.5:1 이상, 큰 제목·아이콘 3:1 이상.

### 4. 손가락과 키보드
- 누르는 대상은 **24×24px 이상**(WCAG 2.2 AA), 휴대폰(`pointer: coarse`)에서는 32px 이상을 목표로 한다.
- hover 효과(표지 들림 등)는 `@media (hover: hover)`에서만. 휴대폰에서 눌렀다 돌아오면 들린 채 남는 일이 없게.
- 화면 밖으로 밀어 둔 패널(목차·설정)은 닫혀 있을 때 `visibility: hidden` — Tab으로 들어가지 않고, 휴대폰에서 가로 스크롤을 만들지 않는다.
- 모든 조작에 보이는 포커스 링.

### 5. 움직임
- 움직임은 0.2–0.35초, 한 방향. `prefers-reduced-motion`이면 끈다.
- 로딩은 맨 위 가는 선 하나. 스피너 없음.

### 6. 일관성
- 색·그림자·여백은 `reader.css`의 테마 토큰(`--bg`, `--fg`, `--fg-muted`, `--accent`, `--ink-hair` …)으로만. 화면 하나에만 쓰는 새 색을 만들지 않는다.
- 서재와 리더는 같은 네 테마(종이·세피아·야간·심야)를 공유한다.

### 평가 (2026-10-13)
- 표제·표지·작은 대문자(small caps)가 기기 글꼴에 맡겨져 있었다: Windows는 Sitka, Mac은 Georgia(가짜 small caps), Android는 Noto Serif — 같은 서가가 세 가지로 보였다.
- UI는 Pretendard를 첫째로 적어 두었지만 싣지 않아, 실제로는 Windows에서 Segoe UI+맑은 고딕, Mac에서 SF+Apple SD 고딕이었다.
- 표제 자리의 한글(머리글 '서재', '읽는 중' 제목, 리더 제목줄, 목차)은 표제 글꼴에 한글이 없어 기기 바탕체로 떨어졌다 — 본문(Noto Serif KR)과 다른 명조.
- 리더 글꼴 설정(콘스탄시아·조지아·산세리프)이 서재 표제와 표지 글꼴까지 바꿨다.

### 기준
| 역할 | 글꼴 | 싣는 방법 |
|---|---|---|
| 표제·표지·숫자 (라틴) | **Source Serif 4** — 광학 크기 축(60px 표제 ↔ 12px 라벨), 진짜 small caps, 옛 숫자 | `서재/fonts/SourceSerif4-*.woff2`, 라틴만·굵기 400–600, 145 KB |
| 표제 자리의 한글 · 한국어 본문 | **Noto Serif KR** (`Seojae Serif KR`) | 기존 그대로, unicode-range로 한글이 나올 때만 |
| UI (한글+라틴) | **Pretendard Variable** | `서재/fonts/pretendard/` 동적 서브셋 — 화면에 나온 글자 조각만 받는다 |
| 영문 본문 | 독자가 고른 것(시트카 등), 없으면 Source Serif 4 | 리더 설정, 서재 화면에는 영향 없음 |
- 모든 글꼴은 사이트와 같은 곳에서 받는다(외부 CDN 없음, 오프라인 서재 원칙).
- 굵기는 400(본문)·600(강조) 두 단계만. 기울임은 영문 부제·인용에만.
- 한글에는 자간을 넓히지 않는다(넓힌 자간·small caps는 라틴 표제에만).

### 기준
- **한 화면에 같은 정보는 한 번만.** 작가 목록·읽는 중 개수처럼 바로 아래에 다시 나오는 것은 뺀다.
- **결정에 쓰이지 않는 수는 보이지 않는다.** 글자 수는 독자가 고르는 데 쓰지 않는다 → 읽는 시간만.
- **모든 책에 똑같이 붙는 것은 정보가 아니다.** 79편 전부에 붙는 '열기 영문/한글/대역'은 hover에만.
- 개인 기록(누적 시간·세션 시간)은 기본으로 숨기고 설정에서 켠다.

### 한 장의 표지로 보이게 (2026-10-13)
- **잉크는 둘**: 글자는 검정, 장식(작가 표식·괘선·틀·가운데 그림·무늬)은 모두 장르 색 하나. 시대 표지가 1–2도 인쇄였던 것처럼.
  요소마다 다른 색을 쓰면 '종이 위에 따로 얹힌 조각'처럼 보인다.
- **틀이 모든 것을 묶는다**: 모든 표지에 인쇄 테두리, 무늬는 틀 안 맨 아래 칸에 괘선으로 닫아 넣는다(흐려지며 사라지는 처리 금지).
- 질감·색 띠·틀은 판지(종이) 쪽, 글자와 장식은 인쇄 쪽 — 두 층만 있다.

### 평가 — '서재 1895—1936'
1. '서재'는 일반명사 — 검색에서 밀리의 서재·수많은 '○○서재'에 묻힌다.
2. 숫자 범위는 소리 내어 부르기 어렵고 기억에 남지 않는다.
3. 1937년 이후 작품이 들어오면 이름이 틀린다.
4. 원문·새 번역·근대 소설이라는 핵심이 이름에 없다.

### 결정 — **모던문고** (2026-10-13, 사용자 선택)
- '모던' = 1920–30년대 '모던'과 모더니즘 시대, '문고' = 고전 총서. 4음절, 부르기 쉽고 범주가 바로 읽힌다.
- 한 줄 소개: **원문과 새 번역으로 읽는 근대 소설**.
- 1895—1936은 이름에서 빼고 제목부의 큰 숫자로 남긴다(시대의 표지, 이름은 아님).
- 화면 안의 '서재'는 '책장 화면'이라는 뜻의 보통명사로 그대로 쓴다(‹ 서재, 서재 열기).
- 주소(URL)와 저장소 이름은 그대로.

### 상표 확인 (2026-10-13)
- KIPRIS(특허정보검색서비스) 국내 상표 '상표명칭' 검색: `모던문고`, `모던*문고`, `모던문고*`, `*모던문고`, `MODERN*BUNKO` — **모두 0건**.
  같은 방법으로 `영풍문고`를 찾으면 3건이 나와 검색 자체는 정상임을 확인.
- 웹 검색(출판사·서점·앱): 같은 이름의 사업자·서비스 없음.
- 한계: 출원 직후라 아직 공개 전인 건, 비슷한 소리·뜻의 상표(예: '모던 라이브러리')까지 판단한 것은 아님.
  상업적으로 키울 생각이면 9류(전자책)·16류(서적)·41류(전자출판·도서관 서비스)로 출원하거나 변리사 확인을 권함.

### 로고
- 원본: 사용자가 만든 Gemini 이미지(집 지붕 + 펼친 책, 지붕 꼭대기에서 책등까지 한 줄, 가는 산세리프 '모던문고 / MODERN BUNKO').
- 사이트에서는 **선 그림 SVG로 다시 그려** 쓴다(`tools/jacket.py` `LOGO_PATHS`) — 어떤 크기에서도 선명하고, 테마 색을 따른다. 작가 표식과 같은 '선 그림' 어휘.
- 32px 아래는 작은 판(가운데 쪽 한 겹을 뺀 것)과 굵은 선.
- 쓰는 곳: 서재 머리 막대, 첫 화면 머리·히어로(전체 로고)·꼬리말, 브라우저 탭 아이콘(종이: 적갈색 / 어두운 브라우저: 밝은 주황), 링크 공유 미리보기(`og.jpg` — 원본 이미지를 잘라 생성기 표시를 뺀 1200×630).
- 글자 로고는 원본처럼 산세리프(Pretendard). 표제·표지의 세리프와 역할이 다르다: 로고 = 서비스, 세리프 = 책.
- **영문 표기는 쓰지 않는다** (2026-10-13). 'Bunko'는 文庫의 일본어 읽기(岩波文庫 = Iwanami Bunko)라 한국 서비스에 일본식 인상을 주고,
  한국어 로마자 'Mungo'는 영어에서 엉뚱한 뜻이 있으며, 'Modern Library'는 미국 출판사(Random House) 총서 이름이다.
  독자가 한국어 사용자이므로 '모던문고' 한글 로고만 쓴다. 공유 미리보기(`og.jpg`)도 로고 + 한글 + 한 줄 소개로 새로 만들었다.

### 연도 '1895—1936'을 어디에 둘까 (2026-10-13)
- 이름이 '모던문고'가 된 뒤로 연도는 브랜드가 아니라 **소장 범위(설명)**다.
- 머리 막대: 뺀다. 로고 옆 숫자는 이름처럼 읽혀 혼란만 준다(Apple Books·리디·밀리·Penguin 모두 막대에는 이름만).
- 첫 화면: 거대한 숫자 대신 **무엇인지 말하는 문장**을 제목으로("원문과 새 번역으로 읽는 근대 소설"), 연도는 그 아래 설명 줄("1895—1936 · 작가 11명 · 소설 79편").
- 서재: 화면 이름 '서재'를 제목으로, 연도는 통계 줄 맨 앞에. 연대별 구분(1890년대 …)은 그대로.
