# 서재 1895—1936 · UI/UX 기준

이 서재의 정체성(종이 바탕, 세리프 제목, 그려서 만든 표지, 작가마다 다른 괘선)은 그대로 두고,
국내외 전자책·서재 서비스가 오래 다듬어 온 사용 관례만 가져온다. 새 화면이나 고침은 아래 기준을 통과해야 한다.

## 참고한 서비스와 가져온 것

| 서비스 | 철학 | 가져온 것 |
|---|---|---|
| Apple Books | 책이 주인공, 크롬은 물러남 | 첫 화면에 '읽는 중', 표지 위주 격자, 정보 위계(제목 → 저자 → 부가정보) |
| Kindle | 읽기 흐름을 끊지 않음 | '이 장 남은 시간', 진행률은 표지·목록에 조용히 |
| Kobo | 읽기 통계와 설정의 세밀함 | 글꼴·여백·정렬을 사용자가 고르되 기본값은 가장 무난하게 |
| Google Play Books | 웹 표준·접근성 | 키보드 조작, 포커스 표시, 화면 밖 패널은 포커스 불가 |
| 리디 | 한국어 본문 조판 | 단어 단위 줄바꿈, 한글 UI 최소 12px (양쪽 정렬 기본값은 브라우저 한계로 보류 — 3. 글자) |
| 밀리의 서재 | 이어 읽기 중심 서재 | 서재 첫 줄에 이어 읽기, 남은 시간 표시 |
| 교보eBook·예스24 크레마 | 큰 손가락, 휴대폰 우선 | 터치 대상 확보, 휴대폰에서 hover 효과 없음 |
| Standard Ebooks | 퍼블릭 도메인 책의 품위 | 장식이 아닌 조판으로 품격, 표지는 활자로 |

## 기준

### 1. 책이 먼저 보인다
- 데스크톱(1280×800 안팎) 첫 화면에 서가 첫 줄 표지 윗부분이 보여야 한다. 제목부(masthead)가 화면의 절반을 넘지 않는다.
- 휴대폰 첫 화면은 제목부를 머리글 크기로 줄인다(이미 적용).
- '읽는 중'이 있으면 서가보다 위, 첫 화면 안에 있다.

### 2. 정보 위계
- 표지 아래 라벨 순서: **제목 → 갈래·저자 → 분량·시간 → 동작(열기 영문/한글/대역)**.
  읽는 정보가 먼저, 누르는 것은 마지막.
- 강조색(accent)은 '진행·선택·한국어판'에만 쓴다. 장식에 쓰지 않는다.

### 3. 글자
- 한글 UI 글자는 **12px 이상**. 숫자 배지·키 표시(kbd)만 예외로 10px까지.
- 표지 안 글자는 '그림'이므로 예외(cqw로 표지 크기를 따라감).
- 본문(한국어)은 `word-break: keep-all` + **왼쪽 정렬이 기본**, 양쪽 정렬은 설정에서 고른다.
  리디·교보 앱은 양쪽 정렬이 기본이지만 그건 글자 사이까지 벌리는 자체 조판기 덕이다.
  브라우저(Chrome)는 `text-justify: inter-character`를 지원하지 않아 낱말 사이만 벌어지고,
  휴대폰 폭에서는 한 줄에 큰 구멍이 생긴다(2026-10 확인). 지원되면 다시 검토한다.
- 대비: 본문·라벨 4.5:1 이상, 큰 제목·아이콘 3:1 이상.

### 4. 손가락과 키보드
- 누르는 대상은 **24×24px 이상**(WCAG 2.2 AA), 휴대폰(`pointer: coarse`)에서는 32px 이상을 목표로 한다.
- hover 효과(표지 들림 등)는 `@media (hover: hover)`에서만. 휴대폰에서 눌렀다 돌아오면 들린 채 남는 일이 없게.
- 화면 밖으로 밀어 둔 패널(목차·설정)은 닫혀 있을 때 `visibility: hidden` — Tab으로 들어가지 않고, 휴대폰에서 가로 스크롤을 만들지 않는다.
- 모든 조작에 보이는 포커스 링.

### 5. 움직임
- 움직임은 0.2–0.35초, 한 방향. `prefers-reduced-motion`이면 끈다.
- 로딩은 맨 위 가는 선 하나. 스피너 없음.

### 6. 일관성
- 색·그림자·여백은 `reader.css`의 테마 토큰(`--bg`, `--fg`, `--fg-muted`, `--accent`, `--ink-hair` …)으로만. 화면 하나에만 쓰는 새 색을 만들지 않는다.
- 서재와 리더는 같은 네 테마(종이·세피아·야간·심야)를 공유한다.

## 글꼴

### 레퍼런스
| 서비스 | 하는 일 | 배울 점 |
|---|---|---|
| Kindle — Bookerly·Ember | 본문·UI 글꼴을 직접 만들어 모든 기기에 싣는다 | 기기가 바뀌어도 같은 책으로 보인다 |
| Apple Books — New York·SF | 제목은 세리프, UI는 산세리프, 역할마다 한 벌 | 역할(표제·본문·UI)마다 글꼴을 하나로 고정 |
| 리디 — 리디바탕 | 한국어 본문용 명조를 자체 배포 | 한국어 명조는 기기 기본(바탕체)에 맡기지 않는다 |
| 밀리의 서재·토스 — Pretendard | 웹·앱 UI를 Pretendard 하나로 | 한글·라틴 UI 글자가 한 벌로 맞물린다 |
| Standard Ebooks | 표지·표제 활자를 정해 두고 모든 책에 같은 규칙 | 표지 글꼴은 '브랜드'다 |
| 서재의 독서 설정 → 책 안에서만 | Apple Books·Kindle은 글꼴 설정이 서재 화면을 바꾸지 않는다 | 본문 글꼴 선택은 리더 안으로 한정 |

### 평가 (2026-10-13)
- 표제·표지·작은 대문자(small caps)가 기기 글꼴에 맡겨져 있었다: Windows는 Sitka, Mac은 Georgia(가짜 small caps), Android는 Noto Serif — 같은 서가가 세 가지로 보였다.
- UI는 Pretendard를 첫째로 적어 두었지만 싣지 않아, 실제로는 Windows에서 Segoe UI+맑은 고딕, Mac에서 SF+Apple SD 고딕이었다.
- 표제 자리의 한글(머리글 '서재', '읽는 중' 제목, 리더 제목줄, 목차)은 표제 글꼴에 한글이 없어 기기 바탕체로 떨어졌다 — 본문(Noto Serif KR)과 다른 명조.
- 리더 글꼴 설정(콘스탄시아·조지아·산세리프)이 서재 표제와 표지 글꼴까지 바꿨다.

### 기준
| 역할 | 글꼴 | 싣는 방법 |
|---|---|---|
| 표제·표지·숫자 (라틴) | **Source Serif 4** — 광학 크기 축(60px 표제 ↔ 12px 라벨), 진짜 small caps, 옛 숫자 | `서재/fonts/SourceSerif4-*.woff2`, 라틴만·굵기 400–600, 145 KB |
| 표제 자리의 한글 · 한국어 본문 | **Noto Serif KR** (`Seojae Serif KR`) | 기존 그대로, unicode-range로 한글이 나올 때만 |
| UI (한글+라틴) | **Pretendard Variable** | `서재/fonts/pretendard/` 동적 서브셋 — 화면에 나온 글자 조각만 받는다 |
| 영문 본문 | 독자가 고른 것(시트카 등), 없으면 Source Serif 4 | 리더 설정, 서재 화면에는 영향 없음 |
- 모든 글꼴은 사이트와 같은 곳에서 받는다(외부 CDN 없음, 오프라인 서재 원칙).
- 굵기는 400(본문)·600(강조) 두 단계만. 기울임은 영문 부제·인용에만.
- 한글에는 자간을 넓히지 않는다(넓힌 자간·small caps는 라틴 표제에만).

## 점검 방법
1. `python -m http.server 8791 --bind 127.0.0.1` 후 1280×800, 390×844에서 확인.
2. 390px에서 `document.documentElement.scrollWidth <= 390` (가로 스크롤 없음).
3. 12px 미만 한글 UI 글자, 24px 미만 터치 대상이 없는지 브라우저 콘솔로 측정.

## 적용 기록
- 2026-10-13 첫 점검·고침
  - 휴대폰 가로 스크롤 67px: 제목부 은은한 빛(`.masthead::before`)이 화면 밖으로 번짐 → `#library{overflow-x:clip}`.
  - 닫힌 목차·설정 패널이 Tab 순서에 남아 있음 → 닫히면 `visibility:hidden`.
  - 데스크톱 첫 화면에 책이 안 보임(1280×800에서 표지 시작 683px) → 제목부 여백·크기 줄여 615px, 표지 윗부분이 보임.
  - 12px 미만 한글 UI 글자(서재 19곳, 리더 20곳) → 12px 이상.
  - 표지 라벨 순서 제목 → 열기 → 저자 → 분량 → **제목 → 저자 → 분량 → 열기**.
  - 휴대폰에서 '영문/한글/대역' 24px → 32px, 표지 들림은 hover 가능한 기기에서만.
