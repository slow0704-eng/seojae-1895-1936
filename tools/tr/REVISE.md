지침 `GUIDE.md` 는 `8cc3004`(2026-10-05)에서 크게 바뀌었습니다(오역 8유형, 번역투 줄이기,
대화 실무, 일본어·중역·편지 규칙, 작품 노트 5절). 그 전에 옮긴 63편을 이 문서대로
**다듬습니다.** 처음부터 다시 옮기는 일이 아닙니다 — 원문과 지금 한국어를 나란히 놓고,
지침에 어긋나는 곳과 틀린 곳만 고칩니다. 잘 된 문장은 그대로 둡니다.

## 입력과 출력

```
python tools/translate.py revise <책>     # 사람이 한 번 돌려 둠
  → tools/tr/rev/<책>/NNN.json           입력: job 과 같고, items 마다 "ko"(지금 번역)가 붙음
  → tools/tr/out/<책>/NNN.json           출력: 지금 번역이 이미 들어 있음. 다듬은 결과로 덮어씀
```

출력 형식은 번역 때와 같습니다 — 키와 값만 있는 평평한 JSON 객체, 입력의 **모든 키**.
고칠 것이 없는 문단도 지금 번역 그대로 넣습니다.

## 순서 (청크 하나마다)

1. 처음 한 번: `tools/tr/GUIDE.md` 전체, `tools/tr/notes/<책>.md` 전체를 읽습니다.
2. `tools/tr/rev/<책>/NNN.json` 을 읽습니다. `prevTail` 은 문맥용.
3. 앞 청크를 맡았다면 그 출력과 결정을 이어받습니다(인명·말투·고정 어휘).
4. 문단마다 `t`(원문)와 `ko`(지금 번역)를 맞대어 아래 **점검표**대로 고칩니다.
5. 다듬은 결과를 `tools/tr/out/<책>/NNN.json` 에 씁니다(Write 도구 또는
   `json.dump(..., ensure_ascii=False)` — 손으로 JSON 을 조립하지 않음).
6. `cd tools && python translate.py check <책>/NNN` — `ok` 가 나올 때까지.
   경고(`대사 수`, `대명사`)가 남으면 다시 보고, 이유가 있으면 그대로 둡니다.
   원문 큰따옴표 속생각을 ‘ ’ 로 바꾼 문단은 `대사 수` 경고가 남는 것이 맞습니다 — 보고에 적고 둡니다.
7. 이 청크에서 새로 정한 것이 있으면 `tools/tr/rev/<책>/<첫청크>-<끝청크>.log.md` 에
   `- NNN p:123: …` 한 줄씩 적습니다. **노트 파일은 직접 고치지 않습니다**(여럿이 동시에
   쓰므로) — 끝난 뒤 사람이 노트의 '결정 기록'으로 옮깁니다.

## 점검표 — 고칠 것

**A. 뜻 (가장 먼저)** — GUIDE '원문 읽기 — 오역이 잦은 자리'의 8유형.
관용구를 낱말로 옮긴 곳, 시대·전문 용어, 숫자·시각·배수, 뒤집힌 부정·반어,
빠진 접속어(but·yet·still·though), 중의적 띄어쓰기, 호칭·멸칭의 수위, 주술 호응이 깨진 긴 문장.
**빠진 문장·구절**이 없는지 원문 문장 수로 확인합니다.

**B. 번역투** — GUIDE '한국어로 쓰기'.
- `그녀`·`그는/그가/그의/그를/그에게`: 생략하거나 이름·관계 명사로. 한 문단에 같은 사람
  `그녀` 셋 이상이면 다시 씀. 단 누가 누구인지 흐려지면 안 됨(두 사람 장면은 이름).
- 기계적 `–들`, 무생물 주어, 명사 덩어리, 진짜 진행이 아닌 `–하고 있었다`.
- *said* 를 「소리쳤다」「속삭였다」로 덧칠한 곳은 「말했다」로. 원문이 *cried* 면 둠.
- `–했다.` 의 기계적 반복은 문장 구조로 풂. **원문 문장 수는 지킴.**

**C. 대화** — GUIDE '대화 실무'.
- 원문 한 문단의 따옴표 대사 수 = 한국어 대사 수. 합친 대사, 지문으로 푼 대사를 되살림.
  쪼개진 대사(*“Yes,” he said, “I know.”*)는 둘로.
- 말투 등급은 노트의 **말투 표**대로. 표와 다르면 표를 따름(노트가 틀렸다고 보이면 고치지 말고 log 에 적음).
- 원문이 큰따옴표로 쓴 **속생각**은 ‘ ’ 로. 이탤릭 생각은 `<em>` 만, 따옴표를 새로 만들지 않음.
- 그 밖의 따옴표 모양은 **원문을 따릅니다**(GUIDE '마크업'). 영국식 홑따옴표 대사를
  “ ” 로 바꾸지 않습니다.
- 대사는 입말로. 사투리·철자 비틀기로 계급을 내지 않음. 욕·감탄의 수위는 원문과 같게.

**D. 노트와 맞추기** — 인명·지명·용어·고정 문구가 노트와 다르면 노트대로.

**E. 갈래별** — 일본어 원작(「」→“ ”, 한자어 음독 금지, 경어, 고어 금지), 중역(영역자의
영국식 관용 덜기, 원어 인명), 편지·시·신문·말장난 — GUIDE 해당 절.

## 도우미 파일

JSON 을 쓰거나 고치는 스크립트가 필요하면 **자기만의 폴더**(`tools/tr/rev/<책>/work-<첫청크>/`)에
둡니다. 여러 다듬는 이가 동시에 돌기 때문에 공용 임시 폴더의 `apply.py` 같은 이름은 서로 덮어씁니다
(시범에서 실제로 남의 스크립트가 남의 청크를 다시 썼습니다).

## 하지 말 것

- 키를 빼거나 만들거나, 문단을 합치거나 쪼개기.
- 고칠 이유가 없는 문장을 취향으로 바꾸기. 바꿀 때마다 위 A–E 중 무엇 때문인지 댈 수 있어야 합니다.
- 노트가 이미 정한 표기·말투를 바꾸기.
- `<em>`, `<span class="smallcaps">` 외의 태그. 굽은 따옴표·줄표·말줄임을 ASCII 로.
- 원문에 없는 감탄사·설명·역주.
