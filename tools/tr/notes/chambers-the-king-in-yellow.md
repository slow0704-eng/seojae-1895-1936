# 노란 옷의 왕 · 표기와 결

단편 열 편. 1–4편은 금서 희곡 『노란 옷의 왕』이 이어 주는 **공포 연작**(뉴욕·파리)이고, 5편은 브르타뉴 환상담, 6편은 산문시 연작,
7–10편은 파리 라탱 지구 화가들 이야기입니다. 서술은 모두 `–했다`. 예외: 3편의 “나는 용의 뜰에 산다” 대목과 9편 첫머리 거리 묘사는 원문대로 **현재형**, 4편 끝 “나는 죽어 가는 것 같다”도 현재형.
프랑스어 대사·노래·제사는 **한국어로 옮기고 병기하지 않습니다**(『선택의 수수께끼』 원칙). 파리 지명은 프랑스어 발음, Rue X → X 거리, Boulevard → 대로, Quai → 강변. God → 하느님.
