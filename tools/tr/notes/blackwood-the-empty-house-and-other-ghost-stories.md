**「스미스」 액자** — 바깥(청중 가운데 '나', 벽난로 가 장면)은 `–했다`. 의사가 청중에게 들려주는 본편(“로 여는 문단들)은
『타임머신』처럼 **하십시오체 `–했습니다`**. 문단마다 “로 열고 이야기 끝 문단에서만 ”로 닫는 원문 방식을 그대로 둡니다.
원문 안쪽 홑따옴표가 뒤집혀 있습니다(`‘Eh?‘ I stammered, ’disturbed…‘`) — 번역에서는 `‘…’`로 바로잡습니다.

**정체를 흐리는 말은 흐린 채로** — something/someone → 무언가/누군가, it → 그것, they → 그것들. 무엇인지 풀어 쓰지 않습니다.
대문자 말(`IT`, `HE`, `Something`, `the Other Person`, `Presence`, `Beings`, `the Hand`)은 그것 · 그 · 무언가 · 또 다른 존재 ·
존재 · 존재들 · 손으로 옮기고, `<em>`은 원문에 `<em>`이 있을 때만 겁니다(대문자라고 새로 달지 않음).
「해골 호수」의 시체 “it”은 끝까지 **그것**(원문 따옴표 “it”은 ‘그것’). 「약속」의 “the breathing”은 **숨소리**.

## 말투
- **빈집** — 이모 → 짐: 해체(“짐”). 짐 → 이모: 해요체(“줄리아 이모”, “이모”). 다급할 때도 등급 유지.
- **엿듣기** — 여주인 → 짐: 느릿하고 퉁명한 하오체(“Waal”=“글쎄”, “그게 방이오. 싫으면 관두구려.”), 사투리 금지. 짐 → 여주인: 하오체(“이보시오, 부인”).
  아버지 → 오토: 해라체(“내놔라!”). 오토 → 아버지: 해요체(“아버지”). 짐 → 옆방(독일어): 하십시오체. 편집장 → 짐: 하게체.
- **약속** — 매리엇 ↔ 필드, 매리엇 ↔ 그린: 해체, 이름으로 부름(“old man”=“이 친구”). 누이 편지: 해체 편지글.
- **절도** — 쇼트하우스 → 나: 하게체(“자네”). 나 → 쇼트하우스: 하십시오체. 들보 위 격투 순간만 둘 다 반말로 터짐(“이 바보야! 당장 내려와!” / “막지 마!”).
- **죽은 숲** — 노인 → 나: 고요한 하오체. 나 → 노인: 하십시오체. 딸 → 나: 해요체+“손님”(sir). 나 → 딸: 해요체. 여관 주인 → 나: 하십시오체.
  노인 → 아내 메리: 하오체(“여보”). 노인 → 딸(환상): 부드러운 해라체(“얘야”). 딸 → 노인 “아버지”: 해요체. 청년 ↔ 처녀: 해체.
- **스미스** — 스미스 → 의사: 낮은 하오체. 의사 → 스미스: 하십시오체. 여주인: 투박한 해요체.
- **선물** — 가방 든 사내 ↔ 블레이크: 하십시오체(사내는 기름진 공손함). 덴마크 사람·프랑스 사람 ↔ 블레이크: 해체.
- **비서** — 사이드보텀 → 쇼트하우스: 하게체(“쇼트하우스 군”). 쇼트하우스 → 사이드보텀: 하십시오체(“사장님”). 가비 → 쇼트하우스: 점잖은 하오체(“쇼트하우스 씨”).
  쇼트하우스 → 가비: 하십시오체. 가비 → 마르크스: 해라체 욕설(“이 빌어먹을 개놈”). 마르크스·마부: 짧은 하오체(“난 위험한 짓 안 하오. 식구가 있소.”).
- **해골 호수** — 안내인(모리스·실버 피즈·행크) ↔ 러시턴: 투박한 하오체, “Mister”=“양반”, 사투리 금지(「웬디고」 행크 식). 안내인끼리 해체.
  러시턴: 거칠게 몰아치는 해체. 교수 ↔ 나: 하게체. 교수 부인 → 나: 해요체(“빨리요, 해리!”). 교수 → 러시턴: 차가운 하오체.
