# 버드나무 · 표기와 결

원문은 앨저넌 블랙우드 「The Willows」(1907). 장은 「I」–「V」 → `1`–`5`(아라비아 숫자만, 제목 없음).
문단 0–325, 청크 001–016(16청크).

## 결

- 1인칭 회상 서술은 `–했다`. 다만 첫 문단(p:0–2)처럼 지리를 설명하는 일반 서술은 원문대로 현재형(「들어선다」「뒤덮인다」).
- 두 사람은 오랜 여행 동무. 서로 **해체**(`–해`, `–야`, `–지`)로 말합니다.
  스웨덴 사람은 말수가 적고 실무적이며 짧게 끊어 말합니다. 끝까지 유지합니다.
- 자연 묘사가 길고 점점 불길해지는 만연체입니다. 문장을 쪼개지 말고
  리듬과 긴장을 그대로 옮깁니다. `something`, `they`, `It`처럼 정체를 흐리는 말은
  `무언가`, `그것들`처럼 흐린 채로 둡니다. 설명을 덧붙이지 않습니다.
- 대사는 짧게 끊긴 말과 줄표(—)로 끊기는 말이 많음 — 줄표를 살리고 말줄임으로 바꾸지 않음.
- 원문의 강조 이탤릭은 `<em>` 으로 유지(「<em>그것들이 우리를 찾아냈어.</em>」).
- 원문 지문 속 “경치”“이성”“느낌”“우리의 삶” 같은 따옴표 강조는 원문 따옴표 그대로 “ ”.

## 결정 기록

### 앞 청크에서 정해진 것
- 장 제목은 아라비아 숫자만: `1`, `2`, `3` …
- 두 사람은 해체로 말하며 서로 “자네”라고 부릅니다. (→ V2 노트에서 「너/네」로 바꿈, 아래 참조)
- 쥠프페(Sümpfe) · 비너발트(Wienerwald) · 피셔라멘트(Fischeramend) · 텔젠(Thelsen) ·
  마르흐강(March) · 플리겐데 브뤼케(Fliegende Brucke) · 포조니(Pozsóny) · 활동사진(bioscope)

### V2 노트 (현재 번역 전수 확인)
- (V2 노트) 2인칭 너/네·자네 섞임 → 너/네로 통일. 너/네 11문단(003 p:43, 010 p:163·171·174, 012 p:219·223,
  014 p:258·267·279·280, 015 p:297) / 자네 9문단(009 p:134·141·148·150·161, 013 p:229·235·244·255).
  해체 어미와도 「너」가 맞음. 앞 노트의 「자네」 규칙은 이것으로 대체 — 009·013을 고칠 때 「자넨」→「넌」.
- (V2 노트) 천막/텐트 섞임 → 천막으로 통일(천막 44회, 텐트 6회는 014 p:281–285만).
- (V2 노트) 키 노/키잡이 노 섞임 → 키 노로 통일(p:119·120 / p:135).
- (V2 노트) 4차원/사차원 섞임(p:174 / p:201, 1:1) → 4차원으로 통일(먼저 나온 쪽).
- (V2 노트) my companion 동무/동행 섞임 → 동무로 통일(동무 21, 동행 4: p:7·27·45·277). my friend 는 「친구」, 9의 traveling companion 「길동무」는 그대로.
- (V2 노트) 앞 노트의 「모래톱(the island / sand-bank)」은 실제 번역과 다름 — the island 는 「섬」(47회),
  모래톱은 sand-bank·모래 끝·강 가운데 작은 섬들에만. p:63 「이 모래톱에 처음 발을 들인」(this island)은 「섬」이 맞음.
- (V2 노트) GUIDE 위반 — p:137 속생각 “우리 둘 중 하나가 …”는 원문 큰따옴표 생각이므로 ‘ ’ 로.
  반대로 p:63 「‘기색’」(원문 “note”)은 생각이 아닌 강조 따옴표라 원문대로 “기색”.
- (V2 노트) They/Them 은 「그것들」(67회), p:206 「저들」 1회만 예외 → 「그것들」.
- 008–009: steering paddle 이 사라진 대목(p:119–135) — 「키 노」, 찢어진 곳 rent/slit 「찢어진 데」「찢긴 틈」.
- 014: p:258 화자의 폭발 “You damned old pagan!” → 「이 빌어먹을 이교도 영감아!」 — 수위 원문과 같게.
- 016: 마지막 p:324 “Their mark!” → 「그것들의 표식이야!」, 노트의 고정 문구로 둡니다.
