**공통 (『말괄량이와 철학자들』에서 이어받음)** — 서술 `–했다`. 끼어드는 “나”(「부잣집」 화자, 「조정자」·「뜨거운 피」의 “내가 말하는”)도 `–했다`, “나”.
원문 대문자 강조는 본문에 거의 없음 — 나오면 `<em>`을 만들지 않고 어순·조사·“정말” 같은 어휘로만. 기존 `<em>`(66곳)·이탤릭 외래어는 유지, 철자 강조(`<em>u</em>sing`, be-<em>oo</em>-tiful)는 한국어 단어 전체나 늘인 음절에 건다(“<em>이용</em>해 먹은”, “아르<em>으</em>음다운”).
차별 표현: colored maid → “흑인 하녀”, negro girl → “흑인 가수 아가씨”, Swede girls → “스웨덴계 처녀들”, Polish washwoman → “폴란드 빨래꾼 여자”(재클린의 모욕 그대로, 한국어 비속어 추가 금지). 인물의 편견(래그스의 “너무 까만” 라자)은 순화하지 않되 덧칠도 않음.
사투리·억양(흑인 하녀 “Miz Andros”, 아이 말, 전차 차장)은 표준어 안에서 어휘·말버릇으로만. 예외: 차장 외침 “앞으로 들어가쇼, 앞에 자리 많수!”, 앤슨의 취한 대사(“브랜디 한 잔 주면 내려갈 수 이써”)는 뭉갬 허용. 원문 가림표 “the —— best caddy”는 “그 —— 최고의 캐디”로 줄표 유지.
darling → “자기”(연인), dear → “여보”(부부). old man/old boy(남자끼리) → “이 친구”. 동명 주의 — 이디(Ede): 「아기 파티」의 아기 / 「조정자」의 이디 카. 조지: 오켈리(8) / 톰킨스(9). 각 편 안에서만.
