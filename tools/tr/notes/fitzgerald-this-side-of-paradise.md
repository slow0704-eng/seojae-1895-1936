장편, 1920. 제사 p:0 브룩 “…글쎄, 낙원의 이쪽이여!… 현자에게는 위안이 별로 없다. —루퍼트 브룩.” p:1은 와일드 제사와 헌사가 한 값(파서) → “경험이란 많은 사람이 자기 실수에 붙이는 이름이다. —오스카 와일드. <span class="smallcaps">시고니 페이</span>에게”.

**말투**
- 베아트리스 → 아모리: 나른하고 과장된 해체(“얘야”, “아모리, 얘”). 아모리 → 베아트리스: 해요체 + 이름. 편지 서명 MOTHER → “엄마가”.
- 몬시뇰 → 아모리: 다정한 해체(대화·편지; MY DEAR BOY → “얘야”), 서명 <span>세이어 다아시</span>. 아모리 → 몬시뇰: 해요체 “몬시뇰”.
- 아모리 ↔ 케리·번·톰·알렉·슬론·페렌비·레이힐·프로기: 해체. 톰 ↔ 아모리 편지: 해체(“친애하는 보즈웰”, 서명 “새뮤얼 존슨”).
- 교사(마고트슨·루니) → 학생: 하게체; 학생 → 교사: 하십시오/해요 “선생님”. 마이라 ↔ 아모리: 아이들 해체, 마이라 어머니 → 아모리 해체.
- 이저벨 ↔ 아모리: 첫 만찬은 해요체 → 서재에서 p:552 “이저벨, 할 말이 있어”부터 끝까지 해체.
- 클래라 → 아모리: 누이 같은 해체(“얘”); 아모리 → 클래라: 해요체(떠받드는 거리, 청혼도 해요체).
- 로절린드 ↔ 아모리: 첫 대면 아모리 p:1495·1497만 해요체 → p:1498 “아모리라고 부를게”부터 둘 다 해체, 이별 장면까지. darling/lover → “자기”, “내 사랑”.
- 로절린드 → 코니지 부인: 해요체(“엄마”, 비꼼도 해요체); 부인 → 딸들·알렉: 해체. 알렉 → 어머니: 해요체. 세실리아 ↔ 로절린드·알렉: 해체.
- 코니지 부인 ↔ 아모리: 해요체. 길레스피 ↔ 로절린드: 해체(로절린드는 차갑게); 길레스피 ↔ 아모리: 해요체. 라이더 → 로절린드: 정중한 해요체, 로절린드 → 라이더: 해체. 소개말 “길레스피 씨, 이쪽은 블레인 씨예요.”
- 엘리너 ↔ 아모리: 건초더미 첫 외침부터 해체(“후안”, “이 바보 영감” 등 장난스러운 막말).
- 질 ↔ 아모리: 속된 해체(“더그”). 올슨 → 아모리: 하게체 “젊은이”, 아모리 → 올슨: 해요체, “닥쳐!”만 반말.
- 페렌비 씨 → 아모리: 하게체 “젊은이”; 아모리 → 페렌비 씨: 해요체, 끝 “선생님도요” 하십시오체. 가빈 ↔ 아모리: 해요체, 아모리 “아, 닥쳐!”. 발로 씨 ↔ 아모리: 하십시오체(아모리 무례는 해요체). 로런스 부인 ↔ 아모리: 해요체.

**희곡 대목(p:1416–1739, p:1794–1909)** — 화자 표시 `이름:`(세실리아: / 로절린드: / 알렉: / 코니지 부인: / 길레스피: / 라이더: / 아모리:), HE/SHE → `그:` / `그녀:`. 괄호 지문은 현재형 `–한다`(Exit → “퇴장한다”, Exeunt → “모두 퇴장.”, Enter X → “X 등장.”). 인물 소개 지문(p:1468–1484)은 원문 시제 따라 현재/과거 섞음. 여러 문단에 걸친 괄호는 여는 값·닫는 값 원문 위치 그대로.

**시·노래·편지** — 원문에서 행이 이미 한 문단으로 붙어 있음. 행 경계(원문 대문자 시작)마다 ` / ` 로 나누고 한 값 안에 둔다. 연 경계에 원문 “ 가 다시 열리면 그대로. 각운 흉내 불필요, 운율감만. 산문시(p:718, p:1384–1385, p:2159, p:2290)는 ` / ` 없이 산문으로. 인용 시(스윈번·브라우닝·키플링·셰익스피어)도 새로 번역.
