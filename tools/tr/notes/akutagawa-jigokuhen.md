# 지옥변 · 표기와 결

**공통 원칙**은 `akutagawa-rashomon.md` 첫 단락을 따릅니다 — 루비 넣지 않음, 인명·지명은 음역, 관직·불교 용어는 한국 한자음,
신분·기물은 보통명사, 옛 시각(半時 반 시진, 更 경)·도량형(間 간, 分 푼)은 원문 단위 그대로. 「 」→“ ”, 안쪽 「 」→‘ ’, ――→ —.

**서술 — 회상 구술체.** 화자는 호리카와 대감을 20년 모신 늙은 가신(家臣, 이름 없음, 스이칸·하카마 차림)이고, 청중(“あなた方” →
“여러분”)에게 처음부터 끝까지 `ございます`로 말합니다(13장 “여러분은 그게 무엇이었다고 생각하십니까?”). 그러므로 이 작품만
**하십시오체 구술**: `–했습니다`, `–였지요`, 추측 `–겠지요/–인 모양입니다`, 반문 `–아니겠습니까`. `–했다`로 쓰지 않습니다.
1인칭 “저”(私), “저희”(私ども). 대감의 행동에는 늘 존대(`–하셨습니다`, `말씀하셨습니다`, 御顔 “얼굴”). 대감을 감싸는 화자의
변명조(“결코 그런 일은 없었습니다”)를 누그러뜨리지 않습니다 — 믿을 수 없는 화자입니다. 과장된 `–옵니다` 투는 대사에만.

**장 제목** — 한자 숫자 → 아라비아 숫자만: `一` → `1`, `二十` → `20`. 끝 연기 `――大正七年四月――` → `—다이쇼 7년 4월—`.

**말투** (서술은 위의 하십시오체 구술)
- 대감 → 요시히데·아랫사람: 위엄 있는 예스러운 해라체(`–느냐`, `–느니라`, `–거라`, `–마`), 1인칭 “나”(予), 2인칭 “너”(その方).
  “그건 안 된다.” · “좋구나. 나도 만족한다.” · “불을 질러라.”
- 요시히데 → 대감: 극존칭 `–하옵니다/–사옵니다/–옵니까`, 1인칭 “소인”. 오만이 비치는 공손함 그대로.
- 요시히데 → 제자: 하게체(“수고스럽겠지만 또 옷을 벗어 주겠나.”), 1인칭 “나”. 잠꼬대·혼잣말·호통은 해라체.
- 제자·화자 → 요시히데·대감: 하십시오체. 화자 → 딸: 조심스러운 하십시오체(“누굽니까”, “이제 처소로 돌아가십시오”).
- 딸 → 도련님·대감: `–하옵소서`, “아비”(父)는 “아버지”. 도련님 → 딸·원숭이: 해라체(“이 귤 도둑놈, 거기 서라.”).
- 승도: 해라체 설교투(“…오상을 모르면 지옥에 떨어질 수밖에 없느니라”).

## 결정 기록
- (V2 다듬기) 이후 결정은 청크 번호와 함께 아래에.
- 002 p:25: 「智羅永寿」(별명 인용, 대사 아님)는 ‘지라에이주’ 홑따옴표로 둠 — check 의 `대사 수 3→2` 경고는 이 때문. 대사 둘은 그대로 살아 있음.
- 002 p:22: 慳貪 → “박정하고”(앞 번역은 “탐욕스럽고”로 強慾 “욕심이 많고”와 겹쳤음).
- 002 p:23·005 p:64·p:72: 傀儡 → “광대 여자”, 女のやうな男/少年 → “여자 같은 사내/소년”. “계집”은 원문보다 거칠어 쓰지 않음.
- 001 p:13: 枉げて赦してとらす → “특별히 용서해 주기로 하마”(“굳이”는 뜻이 다름).
- 003 p:31: 聊か御機嫌を損じた → “조금은 언짢으셨던 듯”(“적잖이”는 뜻이 뒤집힘).
- 004 p:44: 요시히데 → 제자 하게체 유지(“꿈자리가 사납네.”) — 해체 “사나워”가 섞여 있었음.
- 006 p:76: その癖 → “그러면서도”(“그런 주제에”는 사람을 깎는 말로 읽힘).
- 007 p:88: 御意に入る(요시히데가 대감 눈에 듦)에 요시히데 쪽 존대 “드셨던”을 빼고 “눈에 들어 있던”.
- 007 p:97: 요시히데 → 대감 御承知でございませう → “알고 계실 것이옵니다”(말투 표 –옵니다).
- 007 p:99: 罪人の呵責 → “죄인이 형벌에 괴로워하는”(“문초”는 심문). 責苦(010 p:135 “지옥의 고문”)는 그대로 둠.
- 008 p:116: 大殿油の灯影 → “대청 등잔불 빛”(灯影는 불빛). 浅黄の直衣 → “엷은 남빛 평상 관복”(연둣빛 아님).
- 008 p:117: 仔細らしく → “짐짓 엄숙하게”.
- 009 p:125: 罪人の女房 → “죄를 지은 시녀”(女房은 시녀, 노트 女房たち → 시녀들), その女め → “그 계집”(“그년”은 원문보다 거침). p:127 中の女 → “안의 여자”.
- 010 p:134: 金梨子地 → “금가루 뿌린 옻칠”.
- 010 p:137: 開眼の仏 → “갓 점안한 부처님”(불상 점안).
- 010 p:139: 娘を焼き殺されながら → “딸이 불타 죽는 것을 보면서도”(요시히데가 죽이는 것으로 읽히지 않게).
