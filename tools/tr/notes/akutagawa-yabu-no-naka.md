# 덤불 속 · 표기와 결

**공통 원칙**은 `akutagawa-rashomon.md` 첫 단락을 따릅니다 — 루비 넣지 않음, 인명·지명은 음역, 관직·불교 용어는 한국 한자음,
신분·기물은 보통명사, 옛 시각·도량형은 원문 단위 그대로. 「 」→“ ”, ――→ —, ………는 그대로, 괄호 （ ）→ ( ).

**형식** — 서술자 없이 일곱 사람의 진술만 이어집니다. 검비위사의 질문은 원문에 없고, 증인이 되받는 질문(“太刀か何かは見えなかったか？”)
으로만 드러납니다 → **“–냐고요?”/“–말씀입니까?” 꼴로 되받기**(“칼 같은 것은 없었느냐고요? 아니요, 아무것도 없었습니다.”).
각 진술은 그 사람의 1인칭 입말이며 `–했다` 서술을 쓰지 않습니다(망령만 예외, 아래 표).

**화자별 말투** (1인칭 · 등급 · 결)
| 화자 | 말투 |
|---|---|
| 나무꾼 | “저”, 하십시오체. 공손하고 투박, 본 것만 짧게. “그렇습니다.” |
| 행각승 | “소승”, 하십시오체. 점잖고 불교 투. 如露亦如電 → “이슬 같고 또 번개 같은 것”, 沙門 → “출가한 몸” |
| 포졸 | “저”, 하십시오체. 공을 내세우는 수다. 다조마루는 “이놈”, “놈”. 끝에 “…그것도 조사해 주십시오.” |
| 노파 | “저”·“이 늙은것”(姥), 하십시오체. 애원·울먹임. 사위 “사위”, 딸 “딸아이” |
| 다조마루 | “나”, **하오체**(“그 사내를 죽인 건 나요. 하지만 여자는 죽이지 않았소.”). 관리들은 “당신들”. 거침없고 오만 |
| 마사고 | “저”, 하십시오체로 흐느끼는 참회(“…어찌하면 좋겠습니까?”). 남편에게는 해요체(“여보.”, “당신도 죽어 주세요.”) |
| 망령(다케히로) | “나”(おれ), **해라체 독백**(`–했다`, `–않은가?`). 무녀의 입을 빌린 넋두리 — 원문처럼 끊기는 호흡 |

인용 속 대사: 다조마루 → 다케히로 해라체(“저 여자를 어떻게 할 테냐? 죽일까, 아니면 살려 줄까? 대답은 고개만 끄덕이면 된다. 죽일까?”),
