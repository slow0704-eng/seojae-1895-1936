# 영혼을 죽이는 자 · 표기와 결

1919–20년 미국. 첩보원 빅터 클리브스가 몽골 신전에서 돌아온 트레사 노른과 위장 결혼하고, 악마 숭배 교단의 ‘여덟 암살자’를 하나씩 쓰러뜨린다.
**여주인공은 트레사 노른**(신전 이름 쾨케 몽골)입니다 — ‘차오 치아’라는 인물은 원문에 없습니다. 서술은 `–했다`, 3인칭.

**음역 원칙** — 동양 이름은 체임버스가 프랑스 동양학 문헌에서 따온 철자(tch·ou·ï·kh)라 **적힌 철자를 프랑스식으로 읽어** 외래어 표기법에 맞춥니다
(tch→ㅊ, ou→우, ï→이, kh→ㅋ/ㅎ). 실재 지명·인물은 통용 표기(Eighur→위구르, Yuen-San→원산). 지어낸 말은 음역만, 풀이 금지.
원문 오기는 통일: Yulan→율룬, Togrul Kahn/Kahn→칸, Hassini→하사니, XYL-371→XLY-371, Orchard Cove→오키드코브, Tchingniz/Genghis/Ghenghis→칭기즈.

**말투** (서술 `–했다`)
- 클리브스 → 트레사: 1–5장 해요체+“노른 양”, 6장 청혼 뒤 해체(“트레사”, dear→“여보”). 트레사 → 클리브스: 끝까지 해요체. “클리브스 씨” → 7장 이후 “빅터”.
  트레사가 쓰는 my (dear) lord → “내 님”(호칭은 “님”), Heart of the World → “세상의 심장”. 17장 “thou and I”도 해요체 유지.
- 트레사 ↔ 사낭·야르구즈·예지디들: 서로 해라체(“꺼져라!”, “네 수의나 챙겨라”). thou가 나와도 해라체.
- 사낭 → 구출루크: 해라체. 구출루크 → 사낭: 퉁명한 하오체(“알겠소, 투그치”). 페케: 해라체 욕설, 독일식 영어는 **사투리 금지** — 짧게 끊고 어순을 흐트러뜨림. Ja→“야!”, Ach Gott→“아흐 고트!”.
- 트레사 ↔ 율룬·산사: 해체. 율룬·산사 → 클리브스·벤턴·셀든: 해요체+“나리”(thy dear lord → “네 님”). 벤턴·셀든 → 두 처녀: 해요체.
- 아울라 → 클리브스: 나긋한 하오체+“나리”(“나를 보시오, 나리”).
- 레클로 → 클리브스·벤턴·셀든: 하게체+“자네”. 세 사람 → 레클로: 해요체. 클리브스·벤턴·셀든끼리: 해체. 레클로 → 트레사: 해요체(Dear child → “얘야”).
  요원들 ↔ 트레사: 해요체+“클리브스 부인/노른 양”, 트레사 → 그들 “–씨”. 레클로 → 대통령: 하십시오체+“각하”. 대통령·장관들: 하오체.
- 일본인 항해사·호텔 직원·사감 → 손님: 하십시오체. 무대 문지기·도어맨(Say, I dunno): 투박한 해요체, 방언 금지. 전화 속 “Fifty-three, Six-twenty-six speaking” → “53-6-26입니다”.

각주 [1][2][3] 표시는 그대로: [1] “조심해!” 유목 몽골 방언. [2] 우르두 = 황제의 진영. [3] 모칼라 = 이슬람 설교단으로 쓰는 단.
