**「신들의 아들」 현재형** — 서술 `–한다/–이다/–있다`. ‘we/our’는 **우리**로 살림(참모 가운데 하나). 과거 회상 문단(Yesterday… / How curiously we had regarded…)은 과거형. 독자에게 거는 말(If now you should turn your head… take this field-glass… You are not to forget…)은 **하십시오체**(「지금 고개를 돌리시면…」「이 쌍안경을 받으십시오」). 나팔 `<em>Tra-la-la! Tra-la-la!</em>` → `<em>따라라! 따라라!</em>`.

## 말투 (서술은 `–했다`; 속생각 “ ”는 ‘ ’)
- **군 공통** — 상관 → 부하: 하게체, 「성+계급」(「콜터 대위」「프라이스 중위」「모리스 하사」), 사병에게는 해라체도 됨. 부하 → 상관: 하십시오체, 「계급+님」(「장군님」「대령님」「대위님」); “sir”만 있으면 「예」/계급님. 같은 계급끼리: 하오체, 「대위」. 참모끼리(1인칭 편): 하게체 「자네」.
- **하늘의 기수** — 아버지 → 아들: 격식 있는 해라체(“가거라, 그리고 무슨 일이 있어도 네 의무라 믿는 바를 행하라.”). 아들 → 아버지: 하십시오체 「아버지」. 하사 → 드루즈: 해라체(“이봐, 드루즈”). 드루즈 → 하사: 짧은 하십시오체(“예.” “말이었습니다.” “제 아버지입니다.”). 하사 “Good God!” → “맙소사!”
- **아울크리크** — 파쿠하 → 병사: 하게체. 병사 → 파쿠하: 하십시오체. 속생각 ‘ ’ 해라체.
- **리사카** — 브레일 → 대위: 하오체 농담. 장군 → 브레일: 해라체(“저 빌어먹을 바보 세워!”). 나 → 멘덴홀 양: 하십시오체 「부인」(Madam) → 「멘덴홀 양」; 그녀 → 나: 해요체. 말더듬: 첫 음절 반복+붙임표(“내 이-이 달러 걸겠네, 저 도-도랑에 닿기 전에 저-저 친구 쓰러진다고!”). 마지막 “He was bitten by a snake.” → “뱀에 물렸습니다.”
- **콜터 고개** — 장군 → 대령: 하게체 「대령」; 대령 → 장군: 하십시오체 「장군님」(“장군님, 콜터는 저 사람들 손 닿는 데면 어디든 포를 놓고 싶어 할 겁니다.”). 대령 → 콜터·모리슨·윌리엄스·바버: 하게체/해라체. 콜터 → 대령: 하십시오체(지하실에서도: “이 집은 제 집입니다.” “제 아내와 아이입니다. 저는 콜터 대위입니다.”). 대령 “This casemate is not bomb-proof” → “이 포곽은 방탄이 아니군.”
- **최후의 일격** — 핼크로 소령 → 매드웰: 차가운 하오체 「대위」. 매드웰 → 소령: 하십시오체 모욕(“소령님께서 죽는 쪽이 낫겠다고 저는 오래전부터 생각해 왔습니다.”).
- **파커 애더슨** — 장군 → 애더슨: 하게체 「자네」, “my man” → 「이 사람」. 애더슨 → 장군: 하십시오체 「장군님」, 끝까지 재치; 무너진 뒤에도 등급 유지(“장군님, 제발—간청합니다—”). 장군 → 태스먼·해스터릭: 해라체/하게체. 참모장 “by God! it shall be executed” → “맹세코 집행된다.” 장군 마지막 “How silent it all is!” → “참 고요하구나!” / “I suppose this must be death” → “이게 죽음인가 보군.”
- **전초** — 주지사 → 아미스테드: 하게체. 아미스테드 → 주지사: 하십시오체 「주지사님」(“주지사님, 제 집안에서는 그런 일을 하지 않습니다.”). 매스터슨 ↔ 주지사: 서로 하십시오체(「주지사님」/「장군」). 하사 → 주지사: 투박한 하오체(“이 사람이 대위님을 보겠다는데요” → 하십시오체로 대위에게).
- **양심** — 브룬(변장 때) → 초병·대위: 느릿한 하오체, 소박한 어휘, 사투리 어미 금지(“나를 알아볼 줄 알았소, 장군.” “이웃 양반, 뭐 할 말이 있나 보오.” “하트로이 씨가 준 이 통행증은—”). 정체가 드러난 뒤 브룬: 하십시오체 「대위」(“나는 드레이머 브룬, 남군 스파이이자 당신의 포로입니다.”). 하트로이 → 브룬: 하십시오체 「브룬 씨」. 하트로이 → 부관: 하게체.
- **장교의 한 유형** — 캐머런 → 랜섬: 하게체. 고정: “랜섬 대위, 자네는 <em>아무것도</em> 알 권한이 없네. 내 명령에 복종하면 그걸로 충분해.” 랜섬 → 프라이스에게 같은 글자: “프라이스 중위, 자네는 <em>아무것도</em> 알 권한이 없네. 내 명령에 복종하면 그걸로 충분해.” 매스터슨 → 캐머런·랜섬: 하게체(화나면 「랜섬 대위!」 해라체 섞임). 랜섬 → 매스터슨: 하십시오체 「장군님」(“그건 제 소관이 아닌 듯했습니다.”). 모리스 → 랜섬: 하십시오체 짧게. 랜섬 “Grape.” → “포도탄.”
- **조지 서스턴** — 나 → 서스턴: 하게체(퉁명). 서스턴 → 나: 하오체(“구경꾼으로 가겠소.” “안 하겠소.”). 병참관 말더듬: 첫 음절 반복(“ㅈ-저건 도-도망치려는 체-체질을 다-다스리는 그 사람 방-방식이야.”는 금지 → “저-저건 도-도망치려는…”처럼 음절 단위). 포로 남군 → 북군 장교들: 하오체.
- **흉내지빠귀·실종자·판자창·남자와 뱀·시신(저렛)** — 혼잣말 해라체.
- **브라운빌** — 모런 → 에바: 하십시오체 「메이나드 양」. 에바 → 모런: 해요체 「모런 씨」, 교태 부릴 때도 해요체. 베닝 → 자매: 차가운 하오체. 에바 → 베닝: 해요체(“당신이에요. 당신이 이렇게 한 거예요. 당신—당신—당신!”). 베닝 → 모런: 매끄러운 하십시오체 「친구」(my friend). 모런 → 베닝: 하십시오체 적의(“당신은 저 아가씨를 죽인 자입니다. 그 가증스러운 손으로 목을 땄다 해도 다를 게 없습니다.”).
- **지원자** — 틸보디 → 노인: 느물거리는 하오체. 노인 → 틸보디: 하십시오체.
- **시신을 지키는 사람** — 헬버슨 → 하퍼: 하게체(「하퍼」, “youngster” → 「젊은이」). 하퍼 → 헬버슨: 하십시오체 「박사님」. 맨처 → 둘: 느릿한 해체. 흰머리 낯선 이(맨처): 하십시오체 → “damn you! you didn't let me out!” → “젠장, 당신들이 나를 안 꺼내 줬어!”(반말 폭발) → 다시 하십시오체.
- **남자와 뱀** — 드루링 ↔ 부인: 둘 다 해요체(남편은 장난스레 「여보」).
- **지독한 여자** — 도먼 ↔ 메리: 해체. 포퍼 → 일행·부인: 거드름 하십시오체. 바니 편지(p:795–797): 광부 은어, 짧게(“제프 친구: 묘지에서 크게 터뜨렸네…”).
- **알맞은 환경** — 콜스턴 ↔ 마시: 하게체 「마시」/「콜스턴」(콜스턴 격앙 때 「선생」 sir). 원고(p:861–867): 공문체 하십시오체(“본인 제임스 R. 콜스턴은…”), 추신은 마시에게 하게체. 소년 속말 해라체. 사내들 → 소년: 해라체(“너 제법이구나.”). 신문: 신문 문체.
- **판자창** — 멀록 혼잣말 해라체(“내일은 관을 만들고 무덤을 파야겠지…”).
- **레드호스** — 디먼트 → 아이린: **해요체** 편지, 「아이린」·「친구」(dear/dearest → 「아이린」/「내 친구」). 배리츠 → 디먼트: 하십시오체 「디먼트 양」 → 바닷가에서 해요체(“가엾은 사람, 당신을 아프게 할 뜻은 없었어요.” “거니, 내가 덤프스예요!”). 디먼트 → 배리츠: 해요체(“가세요! 제발 가세요, 이—이 서그 같은 사람!”). 서명 `<span class="smallcaps">메리 제인 디먼트</span>`.
- **표범의 눈** — 브레이딩 → 아이린: 해요체 「아이린」. 아이린 → 브레이딩: 담담한 해요체. 말로 ↔ 아내: 둘 다 해요체.

## 고정 문구
- 「하늘의 기수」 “Whatever may occur, do what you conceive to be your duty.” → “무슨 일이 있어도 네 의무라 믿는 바를 행하라.”(두 번 같은 글자) · “Peace, be still.” → “잠잠하라, 고요하라.”
- 「아울크리크」 마지막 문장: “페이턴 파쿠하는 죽어 있었다. 목이 부러진 그의 몸은 아울크리크 다리의 들보 아래에서 좌우로 천천히 흔들리고 있었다.”
- 「실종자」 “Jerome Searing, you are caught like a rat in a trap—in a trap, trap, trap.” → “제롬 시어링, 너는 덫에 걸린 쥐 신세다—덫에, 덫, 덫.” · “Dead a week” → “죽은 지 일주일.” · 6시 18분 / 6시 40분.
- 「장교 하나, 병사 하나」 보고서 끝 “Killed, one officer, one man.” → “전사, 장교 하나, 병사 하나.” 머리 “SIR:” → “각하:”.
