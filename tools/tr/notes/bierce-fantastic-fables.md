우화 245편(각 3–12문단) + 섹션 제목 둘. 한 편이 한 청크 안에 들어가므로 **245편 제목표는 없습니다** — 아래 규칙으로 각자 붙입니다.
되풀이되는 **대문자 역할 명사·고유명사·호칭**은 이 노트의 낱말로 고정합니다(얼룩진 문장·더러운 못·우화 작가·여성 언론인 협회·
성 베드로·마다고니아는 멀리 떨어진 두 편에 다시 나옵니다). 노트에 없는 것을 정하면 `## 결정 기록`에 적습니다.

## 제목 (`h:` 키)

- 우화 제목은 **한국어만, 번호 없음, 관사 없음**. 원문이 대문자지만 보통 표기. `The X and the Y` → 「X와 Y」(받침 따라 와/과).
  셋이면 「X, Y, 그리고 Z」가 아니라 「X와 Y와 Z」. `TWO KINGS` → 「두 왕」, `PHYSICIANS TWO` → 「의사 둘」, `SIX AND ONE` → 「여섯과 하나」.

## 말투
서술은 `–했다`. 교훈 한 줄(“It occurred that way.” → 「그렇게 되었다.」, “Judgment for the plaintiff.” → 「원고 승소.」)은 **설명 없이 짧게**. 대화:

| 말하는 이 → 듣는 이 | 등급 |
|---|---|
| 기본(추상명사·동물·사물·낯선 사람 사이, 정객↔정객, 변호사↔판사 밖) | **하오체**(「–하오」「–구려」「–시오」) |
| 신하·청원자·죄수 → 왕·판사·신·성 베드로·대통령 | 하십시오체 + 폐하/재판장님/각하 |
| 왕·판사·신·성 베드로 → 아랫사람·동물 | 해라체(명령)·하게체(「들어오게, 내 아들」) |
| 포식자 → 먹잇감(사자→푸들, 늑대→양) / 먹잇감 → 포식자 | 하게체 / 하오체(위엄 있게) |
| 아버지·어머니 → 자식 / 자식 → 부모 | 해라체 / 해요체(「아버지」) |
| 노인·현자 → "my son" 젊은이 | 하게체(「젊은이」) |
| 패거리·동료끼리(두 길강도, 두 개구리, 쥐 둘) | 해체 |
| 경관 → 시민 / 경관 → 부인(ch055) | 하오체 / 하십시오체(「부인」) |
| thou/thee 고어(ch010·123·130·171·190) | 「그대」+ 격식 하오체. 왕에게는 「오, 왕이시여」+ 하십시오체. `–하노라` `–이로다` 금지 |

## 문체·마크업
- 짧고 건조. 마지막 반전을 앞당기거나 풀지 않음. 원문의 과장된 수식(「심오한 주의와 전적인 찬동으로」)은 그대로 — 그 격식이 농담.
- `<em>` 23개: 라틴 학명(*Mustela maculata*, *Saltarix mackintosha*)은 **로마자 그대로** `<em>` 안에. *modus vivendi* → 「<em>잠정 협정</em>」. 강조 *me*·*I*·*you*·*that*은 대응 한국어에.
- ch144 대본 형식 유지: `<em>발명가</em>.—“…”` / `<em>왕</em>(총리에게).—“…”`.
- 운문(ch090 4행, ch116 2행)은 `p:` 한 행씩, 행 수 지킴. 원문 끝 따옴표가 뒤집혀 있음(p:410·535 `“`) → 번역은 `”`. ch109 p:495 끝 `‘` → `’`.
- ch109: 편집장의 이어지는 말은 원문처럼 문단마다 `“`로 열고 p:492·496에서만 닫음. 시 한 줄은 세 번 똑같이 「‘가을 잎이 지고 있었네, 지고 있었네.’」(p:495는 끝이 —).
- 「(Cheers.)」 → 「(환호.)」. 날짜·숫자 그대로(1893년 2월 16일, 1994년, 1889년 의회, 5천만 명, 150가지, three hundred and fifty thousand miles → 35만 마일, one thousand million dollars → 10억 달러).
- 말장난은 한국어로 같은 효과가 나면 바꾸고 없으면 뜻만, 역주 없음. 제안: hauls of legislation → 「입법부의 ‘털어 가기’」 · Mr. Shareman → 「분배장님」 ·
