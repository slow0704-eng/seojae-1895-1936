# 번역 지침 — 서재 1895—1936

이 서재의 한국어판은 **읽으려고 만드는 번역**입니다. 대조용 직역이 아니라,
한국어로 소리 내어 읽었을 때 문장이 살아 있어야 합니다. 원문은 모두 퍼블릭
도메인이고, 여기서 만드는 번역문은 새로 쓰는 것입니다.

## 작업 방식

작업 파일 `tools/tr/jobs/<책>/NNN.json` 한 개를 받아, 같은 이름의
`tools/tr/out/<책>/NNN.json` 을 씁니다.

입력:

```json
{"book":"wells-the-time-machine","chunk":3,"of":27,
 "title":"The Time Machine","titleKo":"타임머신","author":"H. G. Wells","year":1895,
 "prevTail":"…바로 앞 문단의 끝부분(문맥용, 번역하지 않음)…",
 "items":[{"k":"h:ch003","t":"III. The Time Traveller Returns"},
          {"k":"p:57","t":"I told some of you last Thursday…"}]}
```

출력 — **키와 값만 있는 평평한 객체**:

```json
{"h:ch003":"3. 시간 여행자가 돌아오다",
 "p:57":"지난 목요일에 몇 분께는 말씀드렸지요…"}
```

규칙:

- 입력 `items` 의 **모든 키**를 출력에 넣습니다. 하나도 빠뜨리지 않습니다.
- 키는 그대로 복사합니다. 새 키를 만들지 않습니다.
- 문단을 합치거나 쪼개지 않습니다. 한 문단은 한 문단입니다.
- 요약·생략·설명 추가 금지. 원문에 있는 내용은 전부 옮깁니다.
- `prevTail` 은 문맥 참고용입니다. 번역해서 출력에 넣지 않습니다.

## 마크업

본문에 나올 수 있는 태그는 두 가지뿐입니다.

- `<em>…</em>` — **그대로 유지**합니다. 강조가 걸린 말에 대응하는 한국어 부분에 겁니다.
- `<span class="smallcaps">…</span>` — 원문의 스몰캡(작품 제목, 신문 헤드라인, 편지 서명 등).
  **그대로 유지**하고 안쪽 글자만 한국어로 바꿉니다.
- 이 둘 말고 다른 태그(`<p>`, `<br>`, `<i>` 등)를 새로 만들지 않습니다.
- 원문 값이 빈 문자열이면 빈 문자열 `""` 로 그대로 둡니다.
- 문자 참조 `&amp;` `&lt;` `&gt;` 는 원문 그대로 둡니다.
- 원문의 굽은 따옴표(“ ” ‘ ’), 줄표(—), 말줄임(…)을 그대로 씁니다.
  ASCII `"` `'` `-` 로 바꾸지 않습니다.

## 문체

**서술**은 `–했다` 평서체로 씁니다. 1인칭 화자도 마찬가지입니다
(`–했습니다` 로 쓰지 않습니다). 단, 화자가 명시적으로 청중에게 말을 거는
액자 구조(예: 타임 여행자가 손님들에게 하는 이야기)는 원문의 말투를 따릅니다.

**대화**는 인물 관계와 시대에 맞춥니다.

- 신사 계급끼리, 처음 만난 사이 → 하십시오체 (`–합니다`, `–하십시오`)
- 친구·형제 → 해체 (`–해`, `–야`)
- 하인이 주인에게 → 하십시오체 / 주인이 하인에게 → 하게체나 해라체
- 어린아이에게 → 해라체

한 인물의 말투는 **작품 전체에서 일관**되어야 합니다. 앞 청크에서 정해진
말투가 있으면 `prevTail` 과 문맥으로 짐작해 맞춥니다.

**리듬.** 원문이 긴 만연체면 한국어도 길게 갑니다. 문장을 잘게 쪼개서
호흡을 바꾸지 않습니다. 반대로 짧고 끊어지는 문장을 접속사로 이어 붙이지도
않습니다.

**하지 말 것**

- 번역투: `–에 의해`, `–되어지다`, `–에 있어서`, `그것은 –이다`, 불필요한 `그/그녀` 반복
- 원문에 없는 감탄사·의성어 추가
- 현대 한국어 구어체 유행어 (`대박`, `진짜`, `–거든요` 남발)
- 존재하지 않는 각주·역주

## 고유명사와 단위

- 인명·지명은 **국립국어원 외래어 표기법**을 따릅니다.
  (Wells → 웰스, Gatsby → 개츠비, Daisy → 데이지, Gregor Samsa → 그레고르 잠자,
  Moreau → 모로, Woking → 워킹, Metropolis → 메트로폴리스)
- 처음 나오는 중요 인명은 한글만 씁니다. 원어 병기는 하지 않습니다
  (리더에 대역 보기가 따로 있습니다).
- 호칭 `Mr.` `Mrs.` `Miss` `Dr.` `Sir` 는 `–씨` `–부인` `–양` `–박사` `–경` 으로
  옮깁니다. 다만 영국 상류 계급 장면에서 `Mr.` 가 반복될 때는 `–씨` 를 매번
  붙이지 말고 자연스럽게 이름만 쓰는 쪽을 택합니다.
- 도량형은 **원문 단위를 유지**합니다 (마일, 야드, 파운드, 실링, 파딩).
  환산값을 괄호로 넣지 않습니다.
- 시대 어휘(개솔린 자동차, 전신, 하숙집, 마차)는 그 시대 말로 옮깁니다.

## 작가별 결

- **카프카** — 건조하고 사무적인 문장. 초현실적 사건을 관공서 보고서처럼 씁니다.
  감정을 덧칠하지 말고, 문장의 차가움을 지킵니다. 긴 종속절 구조를 유지합니다.
- **웰스** — 과학적 설명과 영국식 사회 관찰이 섞입니다. 설명 부분은 명료하게,
  희극적 인물(폴리, 킵스, 빌비)의 말은 계급이 드러나는 입말로.
- **피츠제럴드** — 문장이 음악입니다. 형용사 배열과 마지막 절의 여운을 살립니다.
  화려한 수사를 평범한 말로 눌러 쓰지 않습니다.
- **하르부** — 표현주의. 짧고 강한 단문, 반복, 대문자 같은 과장된 리듬이 있습니다.
  그 과장을 그대로 둡니다.

## 마지막 점검

출력 JSON을 쓰기 전에:

1. 입력 키 개수 = 출력 키 개수인가
2. `<em>` 여는 태그와 닫는 태그 수가 각 값에서 맞는가
3. 영어 문장이 그대로 남은 값이 없는가
4. JSON이 유효한가 (값 안의 `"` 는 `\"` 로 이스케이프, 줄바꿈 금지)
